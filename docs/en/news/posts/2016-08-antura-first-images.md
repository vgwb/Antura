# First Images of Antura and the Letters

In August 2016, VGWB shared the first screenshots from the Alpha version of Antura and the Letters. The game was being developed with Cologne Game Lab and Wixel Studios for the EduApp4Syria competition, which aimed to create a learning tool for Syrian children.

The team was awaiting the competition jury's decision on which projects would continue to the next stage.

Source: [VGWB News](https://vgwb.org/2016/08/antura-and-the-letters/).
