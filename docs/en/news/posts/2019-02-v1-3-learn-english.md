# Antura and the Letters 1.3.0: Learn English

Released in February 2019, version 1.3.0 was the first Learn English release. It included Stage 1 with basic vocabulary; voice recordings were still placeholders.

The app was designed to support a native language for instructions and a separate language for learning.
